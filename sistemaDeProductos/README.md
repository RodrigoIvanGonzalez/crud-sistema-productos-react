# Product Management CRUD

Sistema de gestión de productos desarrollado con React.
Permite crear, editar y eliminar productos utilizando estado local y persistencia en LocalStorage.

## Tecnologías
- React
- Hooks
- Vite
- LocalStorage

## Funcionalidades
- CRUD de productos
- Formularios controlados
- Validaciones básicas
- Feedback visual y estados vacíos

## Instalación
```bash
npm install
npm run dev
